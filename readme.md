# Ma souris et moi

Micro-site HTML5 pour **apprivoiser la souris sous Windows 11**, conçu pour des ateliers d'initiation au numérique auprès de publics éloignés de l'outil informatique.

8 petites activités ludiques, sans chronomètre ni échec possible : on essaie, on recommence.

## Les activités

| # | Activité | Geste travaillé |
|---|----------|-----------------|
| 1 | Bien installer sa souris | Posture de la main (paume, index, majeur) |
| 2 | Le rond à effleurer | Déplacer la souris, sans cliquer |
| 3 | Le rond qui bouge | Clic gauche |
| 4 | Le dossier | Double-clic |
| 5 | Le bouton droit | Clic droit et menu contextuel |
| 6 | Les paniers | Glisser-déposer |
| 7 | Le chemin | Précision du pointeur, sans cliquer |
| 8 | Mon premier bureau | Synthèse sur un faux bureau : ouvrir, copier, glisser, fermer |

## Principes pédagogiques

- **Progression** du plus simple (poser la main) au plus complet (tâche réaliste).
- **Démonstration animée** avant chaque exercice, avec un bouton pour la revoir.
- **Lecture à voix haute** des consignes (voix du navigateur).
- **Difficulté adaptative** : la taille des cibles s'ajuste selon les réussites et les essais manqués (ou réglage fixe : grande, moyenne, petite).
- **Aides bienveillantes**, jamais de note ni de pénalité.
- **Bilan** par activité (essais manqués, temps, taille des cibles), imprimable.

## Utilisation

Le site tient dans **un seul fichier** : `index.html`. Aucune installation, aucune dépendance, aucune connexion Internet requise.

- **En local** : ouvrir `index.html` dans un navigateur (testé avec Chrome).
- **En ligne** : publier avec GitHub Pages (Settings › Pages › Deploy from a branch › `main` / `(root)`).
- **Plein écran** : touche `F11`.

## Conseils pour l'animateur

- Prévoir environ 10 minutes par activité ; montrer le geste, puis laisser faire.
- Commencer en taille de cibles « Grande » ou « Auto ».
- Réglages Windows 11 utiles : inversion des boutons pour les gauchers, vitesse du double-clic et agrandissement du pointeur (Paramètres › Bluetooth et appareils › Souris, et Accessibilité › Pointeur de la souris et toucher).
- Sur un pavé tactile, le clic droit se fait en touchant avec deux doigts.

## Vie privée

Aucune donnée n'est envoyée. Les réglages, les ★ et le bilan sont enregistrés uniquement dans le navigateur de l'ordinateur utilisé (`localStorage`).
